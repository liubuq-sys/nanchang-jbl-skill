# 图片素材

## 使用说明
当顾客询问相关资质、授权、门店实景等时，可以发送对应图片作为参考。

## 图片目录
图片文件存储在 `images/` 目录下，AI 可根据场景发送给顾客。

## 常见触发场景
- **品牌授权**：顾客问"你们是正规代理吗？""有授权书吗？" → 展示授权书图片
- **资质证书**：顾客问"有资质吗？""正规吗？" → 展示资质证书图片
- **门店实景**：顾客问"店怎么样？""有照片吗？" → 展示门店实景图片
- **荣誉展示**：顾客问"口碑怎么样？""做过什么工程？" → 展示荣誉证书图片
